## ⚖ DECISIONS, SO THEY ARE NOT RE-LITIGATED OR RE-DERIVED WRONGLY

1. **`copymode`, NOT `copystat`.** Measured side by side: `copystat` restores the mode AND the
   timestamps, so a repointed file claims it was never modified; `copymode` lets mtime advance,
   which matches the pre-0.4.5 `write_text` semantics exactly. **Restore the property that was
   lost, not every property the API offers.** `copystat` also propagates macOS `st_flags`, which
   breaks the fail-closed cleanup on a `chflags uchg` config. **The mtime is now ASSERTED** —
   before that, the most heavily argued line in the diff was the one nothing checked.
2. **The mode is restored; ACLs and xattrs are NOT.** `shutil._copyxattr` is a no-op on darwin.
   Documented at the fix site and in the CHANGELOG rather than papered over. **Named, not fixed.**
3. **Hardlinked configs still lose their link.** No atomic-rename form preserves one; the
   alternative is writing through the inode, which is the truncation risk the atomic write
   removes. **Known-open, in the CHANGELOG.**
4. **Parity pin, not deduplication.** Extracting a shared request preamble across two web-facing
   servers is a DESIGN change with real blast radius — routed, like `spore-861`. What is taken is
   the invariant.
5. **The `[Unreleased]` CHANGELOG entry is a DISCLOSURE and must not be softened.**
   ⚖ Phill: *"levain = let this ride to next release."* That governs THE CUT, not the code.
   **Upgrading does not repair an already-changed file** — that sentence has to survive to the
   released notes whenever the release happens.
