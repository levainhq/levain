install, exit 1 forever, and the remedy it prints does not clear it.**

**Ritual verified this against disk independently of Diogenes' repro.** The loop at
`levain/doctor.py` iterates `(templates_root/"activation"/"hooks",
templates_root/"adapters"/"codex"/"activation"/"hooks")` and `break`s after the first present
dir, under the comment *"the first present tree is this install's lineage."* That comment is
false: `templates/activation/hooks` **always ships**, so the loop always breaks on the
claude-code tree and the codex branch is unreachable. A codex install's hooks are therefore
compared against the claude-code hooks, which legitimately differ (147 diff lines) → doctor
reports "installed hook script(s) differ from the package" and exits 1. `levain init --force`
reinstalls the *codex* hooks, which still differ from the tree it compares against, so the
printed remedy fails again.

**Why this matters more than its size.** 0.4.0 was published 2026-08-01 specifically to carry
Alex's `install_root` fix — a check that pointed at the wrong thing — to operators. The commit
that fixed it shipped a NEW check with the same category of defect, and it is now on PyPI. A
codex operator's first act on a fresh install is `doctor`. The check written to deliver the
signal is the thing destroying it.

**The fix is one line and the machinery already exists:** `run_doctor` already imports and calls
`effective_adapter(install)` (`doctor.py:76`, used for the `hookless`/openhands branch). Select
the shipped tree by adapter instead of by first-present.

**Missed for the reason the commit message itself names for `install_root`:** no test constructs
a codex install — `_hooked_install` (`test_doctor_content.py:455`) copies from the claude-code
tree only. **This is the second occurrence of "the branch under the layer was never executed by
the suite," in the very commit that named the pattern.** A codex-install fixture is the real fix;
the one-liner is the patch.

**Ritual's recommendation (Phill's call):** worth a **0.4.1 patch**, not worth doing under a
