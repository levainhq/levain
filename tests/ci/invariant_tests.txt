# The whole-tree invariant tests: each asserts something about EVERY file of the source tree (no module but X calls Y,
# every call site names Z, a table is in exactly one class, every verb the README lists exists), so each can go red from
# a change in a file the author never opened. The marker exists so just this tier can run on its own
# (`pytest -m invariant`): first in CI, ahead of the heavy jobs, so a red here stops the run before the expensive work,
# and on the laptop as a cheap check. It is not a pre-push hook, because the tier is over a pre-push time budget.
#
# Membership is derived, not remembered: (1) every test function that scans the tree (rglob over the package, os.walk,
# git ls-files), found by walking each test module's AST through its helpers, minus the behavioural tests that only glob a
# scratch directory; (2) every whole-tree test named in a failed `test` run among the last 40 on the day this was cut.
# tests/conftest.py applies the marker to the node ids below (function level; a parametrized test is marked whole);
# tests/test_ci_invariant_marker.py holds the list to the collected tests and holds the named failures in it.
